# 3. 小程序的数据绑定机制是怎样的？

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/QwmHwAqJYiktztkd3S9cRpQUn5r)

参考答案：

小程序使用单向数据绑定机制：

数据绑定语法：

```javascript
// 页面数据定义
data: {
  message: 'Hello World',
  userInfo: {
    name: '张三',
    age: 25
  }
}
```

```xml
<!-- WXML中使用 -->
<view>{{message}}</view>
<view>{{userInfo.name}}</view>
```

数据更新：

- 必须使用setData()方法更新数据
- setData()会触发视图层重新渲染
- 支持部分更新：this.setData({'userInfo.name': '李四'})

注意事项：

- 不能直接修改this.data
- setData()是异步的
- 频繁调用setData()会影响性能
