# 5. 常用的HTML标签有哪些？

> 来源：[飞书原文](https://my.feishu.cn/docx/GcXLdcs8LoZ1ARxtlVvcPUVUnOb)

参考答案：

常用的HTML标签分类：

1. 文本标签：
  - &lt;h1&gt; 到 &lt;h6&gt;：标题标签
  - &lt;p&gt;：段落标签
  - &lt;span&gt;：行内文本标签
  - &lt;strong&gt;、&lt;em&gt;：强调标签

2. 结构标签：
  - &lt;div&gt;：块级容器
  - &lt;header&gt;、&lt;nav&gt;、&lt;main&gt;、&lt;footer&gt;：语义化结构标签

3. 列表标签：
  - &lt;ul&gt;、&lt;ol&gt;、&lt;li&gt;：无序和有序列表

4. 链接和媒体：
  - &lt;a&gt;：链接标签
  - &lt;img&gt;：图片标签
  - &lt;video&gt;、&lt;audio&gt;：多媒体标签
