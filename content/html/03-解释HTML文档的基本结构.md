# 3. 解释HTML文档的基本结构

> 来源：[飞书原文](https://my.feishu.cn/docx/GcXLdcs8LoZ1ARxtlVvcPUVUnOb)

参考答案：

HTML文档的基本结构如下：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>
```

- &lt;!DOCTYPE html&gt;：文档类型声明，告诉浏览器这是HTML5文档
- &lt;html&gt;：根元素，包含整个页面内容
- &lt;head&gt;：头部元素，包含元数据，不显示在页面上
- &lt;body&gt;：主体元素，包含页面的可见内容
