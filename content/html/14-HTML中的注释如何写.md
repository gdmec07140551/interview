# 14. HTML中的注释如何写？

> 来源：[飞书原文](https://my.feishu.cn/docx/GcXLdcs8LoZ1ARxtlVvcPUVUnOb)

参考答案：

HTML注释用于在代码中添加说明，不会在浏览器中显示：

1. 基本语法：

  ```html
<!-- 这是一个注释 -->
```

2. 单行注释：

  ```html
<!-- 这是页面头部 -->
<header>...</header>
```

3. 多行注释：

  ```html
<!--
这是一个多行注释
可以包含多行内容
用于详细说明
-->
```

4. 注释的用途：
  - 解释代码功能
  - 临时禁用代码
  - 添加开发者注释
  - 标记代码段落

5. 注意事项：
  - 注释不能嵌套
  - 注释内容不应包含 --
  - 注释在源代码中可见，不要包含敏感信息
