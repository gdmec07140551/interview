# 13. 什么是HTML实体？常用的有哪些？

> 来源：[飞书原文](https://my.feishu.cn/docx/GcXLdcs8LoZ1ARxtlVvcPUVUnOb)

参考答案：

HTML实体用于显示保留字符和特殊字符：

1. 为什么需要HTML实体：
  - 某些字符在HTML中有特殊含义（如 &lt;、&gt;、&）
  - 需要使用实体来正确显示这些字符

2. 常用HTML实体：
  - &lt; → &lt; （小于号）
  - &gt; → &gt; （大于号）
  - &amp; → & （和号）
  - &quot; → " （双引号）
  - &apos; → ' （单引号）
  - &nbsp; → 不间断空格
  - &copy; → © （版权符号）
  - &reg; → ® （注册商标）

3. 数字实体：
  - &#60; → &lt;
  - &#62; → &gt;
  - &#38; → &
