# 6. HTML属性是什么？如何使用？

> 来源：[飞书原文](https://my.feishu.cn/docx/GcXLdcs8LoZ1ARxtlVvcPUVUnOb)

参考答案：

HTML属性用于为HTML元素提供额外信息：

1. 属性的特点：
  - 属性总是在开始标签中定义
  - 属性以名称/值对的形式出现：name="value"
  - 属性值应该用引号包围

2. 常用属性：
  - id：元素的唯一标识符
  - class：元素的类名，用于CSS样式
  - src：指定资源的URL（如图片、脚本）
  - href：指定链接的目标URL
  - alt：图片的替代文本

3. 示例：

  ```html
<img src="image.jpg" alt="描述文字" class="photo">
<a href="https://example.com" target="_blank">链接</a>
```
