# 11. 什么是 OSI 七层模型和 TCP/IP 四层模型？


> 分类：计算机网络

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/SKQgwolgNiwW3BkoaQecUVXhnRc)

参考答案：

- OSI 七层模型（理论模型）：
  1. 物理层： 传输比特流。
  2. 数据链路层： 将比特流组装成帧，进行差错控制。
  3. 网络层： 路由选择，逻辑寻址（IP）。
  4. 传输层： 端到端的连接，可靠传输（TCP/UDP）。
  5. 会话层： 建立、管理和终止会话。
  6. 表示层： 数据格式转换、加密解密。
  7. 应用层： 为用户提供网络服务（HTTP, FTP）。
- TCP/IP 四层模型（事实标准）：
  1. 网络接口层（数据链路层/物理层）： 对应 OSI 的物理层和数据链路层。
  2. 网际层（网络层）： 对应 OSI 的网络层，核心协议是 IP。
  3. 传输层： 对应 OSI 的传输层，核心协议是 TCP 和 UDP。
  4. 应用层： 对应 OSI 的会话层、表示层和应用层。
