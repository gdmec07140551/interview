# 24. 问题： 写一个函数将二维数组扁平化。


> 分类：数组操作题（16-25题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function flattenArray(arr) {
    return arr.flat();
}
// 或者递归方法
function flattenArray(arr) {
    let result = [];
    for (let item of arr) {
        if (Array.isArray(item)) {
            result.push(...flattenArray(item));
        } else {
            result.push(item);
        }
    }
    return result;
}
```
