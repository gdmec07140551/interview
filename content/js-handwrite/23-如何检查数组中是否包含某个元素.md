# 23. 问题： 如何检查数组中是否包含某个元素？


> 分类：数组操作题（16-25题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function containsElement(arr, element) {
    return arr.includes(element);
}
// 或者
function containsElement(arr, element) {
    return arr.indexOf(element) !== -1;
}
```
