# 16. 问题： 写一个函数移除数组中的重复元素。


> 分类：数组操作题（16-25题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function removeDuplicates(arr) {
    return [...new Set(arr)];
}
// 或者
function removeDuplicates(arr) {
    return arr.filter((item, index) => arr.indexOf(item) === index);
}
```
