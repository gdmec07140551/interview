# 45. 问题： 如何检查字符串是否以特定前缀开始？


> 分类：字符串处理题（36-45题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function startsWith(str, prefix) {
    return str.startsWith(prefix);
}
// 手动实现
function startsWith(str, prefix) {
    return str.substring(0, prefix.length) === prefix;
}
```
