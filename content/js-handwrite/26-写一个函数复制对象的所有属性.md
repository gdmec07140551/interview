# 26. 问题： 写一个函数复制对象的所有属性。


> 分类：对象操作题（26-35题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function copyObject(obj) {
    return {...obj};
}
// 或者
function copyObject(obj) {
    return Object.assign({}, obj);
}
// 深拷贝
function deepCopy(obj) {
    return JSON.parse(JSON.stringify(obj));
}
```
