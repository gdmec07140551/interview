# 10. 问题： 写一个函数检查字符串是否包含特定子字符串。


> 分类：基础语法题（1-15题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function containsSubstring(str, substring) {
    return str.includes(substring);
}
// 或者
function containsSubstring(str, substring) {
    return str.indexOf(substring) !== -1;
}
```
