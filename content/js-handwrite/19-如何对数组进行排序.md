# 19. 问题： 如何对数组进行排序？


> 分类：数组操作题（16-25题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
// 数字排序
let numbers = [3, 1, 4, 1, 5];
numbers.sort((a, b) => a - b); // 升序
numbers.sort((a, b) => b - a); // 降序

// 字符串排序
let strings = ['banana', 'apple', 'cherry'];
strings.sort(); // 字母顺序
```
