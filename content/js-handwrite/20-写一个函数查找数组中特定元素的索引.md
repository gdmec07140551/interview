# 20. 问题： 写一个函数查找数组中特定元素的索引。


> 分类：数组操作题（16-25题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function findIndex(arr, element) {
    return arr.indexOf(element);
}
// 或者使用findIndex方法
function findIndex(arr, condition) {
    return arr.findIndex(condition);
}
```
