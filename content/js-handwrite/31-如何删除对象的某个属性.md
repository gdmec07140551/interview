# 31. 问题： 如何删除对象的某个属性？


> 分类：对象操作题（26-35题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function deleteProperty(obj, prop) {
    delete obj[prop];
    return obj;
}
// 或者创建新对象
function deleteProperty(obj, prop) {
    let {[prop]: deleted, ...rest} = obj;
    return rest;
}
```
