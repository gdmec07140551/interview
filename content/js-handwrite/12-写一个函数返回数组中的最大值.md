# 12. 问题： 写一个函数返回数组中的最大值。


> 分类：基础语法题（1-15题）

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/WA8Cw0NJFiEDSWkfEnNciVmrnww)

答案：

```javascript
function findMax(arr) {
    return Math.max(...arr);
}
// 或者
function findMax(arr) {
    let max = arr[0];
    for (let i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```
