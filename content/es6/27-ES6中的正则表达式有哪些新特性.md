# 27. ES6中的正则表达式有哪些新特性？

> 来源：[飞书原文](https://my.feishu.cn/docx/QFVxdRXAxoQN9Hxo22ScylnXnsc)

参考答案：

ES6为正则表达式添加了新特性：

1. u标志：Unicode模式，正确处理大于\uFFFF的Unicode字符
2. y标志：粘连模式，从lastIndex位置开始匹配
3. RegExp构造函数增强：可以接受正则表达式作为参数
4. 新方法：flags属性获取修饰符

```javascript
const regex = /\u{1D306}/u; // Unicode模式
const sticky = /hello/y;    // 粘连模式
regex.flags; // 'u'
```
