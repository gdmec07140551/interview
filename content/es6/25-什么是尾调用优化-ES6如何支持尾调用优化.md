# 25. 什么是尾调用优化？ES6如何支持尾调用优化？

> 来源：[飞书原文](https://my.feishu.cn/docx/QFVxdRXAxoQN9Hxo22ScylnXnsc)

参考答案：

尾调用是指函数的最后一步调用另一个函数。尾调用优化是指在尾调用时不增加新的栈帧，而是复用当前栈帧。

ES6在严格模式下支持尾调用优化：

```javascript
'use strict';
function factorial(n, acc = 1) {
  if (n <= 1) return acc;
  return factorial(n - 1, n * acc); // 尾调用
}
```

条件：

- 严格模式
- 尾调用不访问当前栈帧的变量
- 尾调用是函数的最后一个操作
