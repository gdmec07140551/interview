# 21. ES6中的对象字面量有哪些增强？

> 来源：[飞书原文](https://my.feishu.cn/docx/QFVxdRXAxoQN9Hxo22ScylnXnsc)

参考答案：

ES6对象字面量增强包括：

1. 属性简写：{name, age} 等价于 {name: name, age: age}
2. 方法简写：{method() {}} 等价于 {method: function() {}}
3. 计算属性名：{[key]: value}
4. 可以使用表达式作为属性名
5. super关键字：在方法中调用原型方法

```javascript
const name = 'John';
const obj = {
  name,                    // 属性简写
  greet() {},             // 方法简写
  [name + 'Key']: 'value' // 计算属性名
};
```
