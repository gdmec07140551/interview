# 28. 什么是二进制和八进制字面量？

> 来源：[飞书原文](https://my.feishu.cn/docx/QFVxdRXAxoQN9Hxo22ScylnXnsc)

参考答案：

ES6提供了二进制和八进制数值的新写法：

```javascript
// 二进制（0b或0B开头）
const binary = 0b1010; // 10
const binary2 = 0B1010; // 10

// 八进制（0o或0O开头）
const octal = 0o755; // 493
const octal2 = 0O755; // 493

// 检测方法
Number.isFinite(binary); // true
Number.isInteger(octal); // true
```

注意：严格模式下不支持0开头的八进制写法。
