# 12. 如何实现元素的水平垂直居中？

> 来源：[飞书原文](https://w0hog67yl81.feishu.cn/wiki/KrzqwnIMfiVDAAkVDHWc7fq9nde)

参考答案：

1. Flexbox方法：

```css
.center {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

2. Grid方法：

```css
.center {
    display: grid;
    place-items: center;
}
```

3. 绝对定位 + transform：

```css
.center {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```

4. 绝对定位 + margin：

```css
.center {
    position: absolute;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    margin: auto;
    width: 200px;
    height: 100px;
}
```

5. table-cell方法：

```css
.center {
    display: table-cell;
    text-align: center;
    vertical-align: middle;
}
```

6. line-height方法（单行文本）：

```css
.center {
    height: 100px;
    line-height: 100px;
    text-align: center;
}
```
